# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/Agent365-dotnet/issues) to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a new issue.

For help and questions about using the Microsoft Agent 365 SDK, please refer to the [Microsoft Agent 365 Developer documentation](https://learn.microsoft.com/en-us/microsoft-agent-365/developer/).

For security vulnerabilities, do not file a public issue. Follow the instructions in [SECURITY.md](SECURITY.md).

Release notes and version history are available in [CHANGELOG.md](CHANGELOG.md).

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This is an open-source project, and Microsoft product support contracts and service level agreements (SLAs) do not extend to this repository.
